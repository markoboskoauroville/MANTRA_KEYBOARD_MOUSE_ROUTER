# The icon

`six_1024.png` is made by `STAR_SWIFT/icons6` (the six-letter maker), from the row in its `icons.json`:

    ["kmrouter", "KEY", "MSE", "sf:cursorarrow"]
    category "Between Marko and Claude", colour #000000

Marko, 12.11.2026: "Make it black with some text over it and a cursor in that style."
Remake it with: `cd ~/Developer/STAR_SWIFT/icons6 && swift six_icon.swift icons.json out kmrouter`
and copy `out/kmrouter/icon_1024.png` here as `six_1024.png`. `build.sh` turns it into the iconset.
